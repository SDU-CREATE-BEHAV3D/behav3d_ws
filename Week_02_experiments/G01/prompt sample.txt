This is an example of how you could use codex to do a first quick scan of the log, remember to recheck the facts and once you are done you can also export the data into vector files (such as svg) to edit and adjust the plot visuals.
Use it as a reference for your own relevant metrics.

Analyze the Behav3D capture log located at:

LOG_FOLDER_PATH

Treat every cycle containing:

field_loop/cycle_XXXX/candidates/targets.yaml

as a completed print cycle. Do not count scan-only cycles. If the capture folder was renamed, locate it using the timestamp contained in the original folder name and report the updated path.

Unless specified otherwise, assume that each target represents one printed bead. Exclude these cycles if applicable:

EXCLUDED_CYCLES: none

Perform the following analysis:

1. Target validation
- Count the cycles containing targets.yaml.
- Report the first and last printed cycle.
- Count the targets in every cycle and in total.

2. Z-growth analysis
- Calculate the mean, median, minimum, and maximum target Z for every cycle.
- Calculate the change in mean Z between consecutive cycles.
- Calculate:
  - Total mean-Z gain
  - Endpoint average Z gain per cycle
  - Linear-regression Z gain per cycle
  - R² of the linear fit
  - Median cycle-to-cycle gain
- Identify cycles with negative or unusually large Z changes.
- Explain that fluctuations may occur when the number of targets changes or when targets belong to different sides or columns of the structure.

3. Extrusion-volume analysis
Use these values unless the cycle configuration specifies something different:

- 7,000 net extrusion steps per bead
- 0.8148733086 steps/mm³
- One target equals one bead

Calculate:

volume_per_bead_mm3 = 7000 / 0.8148733086

Report:
- Volume per bead in mm³ and mL
- Beads and theoretical volume per cycle
- Cumulative beads and volume by cycle
- Total net extrusion steps
- Total theoretical volume in mm³, mL, and liters
- Average beads and volume per cycle

Verify the print mode, dot_steps, extrusion_steps_per_mm3,
candidate_volume_factor, and whether any target has a volume_mm3
override. Do not include retract steps in the net material volume.

4. Graphs
Create these PNG files inside the capture folder:

average_z_gain_by_cycle.png
- Mean target Z by cycle
- Linear trend and slope
- Target count represented by point color
- Cycle-to-cycle Z gain as a second panel
- Overall average gain marked with a horizontal line

volume_and_bead_history.png
- Beads deposited per cycle
- Theoretical volume per cycle
- Cumulative bead count
- Cumulative theoretical volume
- Final totals clearly labeled

5. Final report
- Number of printed cycles
- Total and average targets/beads
- Total and average Z gain
- Linear trend and R²
- Volume per bead
- Total theoretical volume
- Any anomalies or assumptions

Do not modify the original capture data. Only create the requested graphs
and optional analysis files.
